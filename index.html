سازنده کانفیگ AmneziaWG

یک دستگاه WARP تازه ثبت می‌شود و کانفیگ آماده‌ی اپ AmneziaVPN ساخته می‌شود. کلیدها در مرورگر خودتان ساخته می‌شوند.

خالی بگذارید تا از آدرس پیش‌فرض WARP استفاده شود.

روی هر آی‌پی بزنید تا در فیلد بالا قرار بگیرد. کانفیگ بسازید، وصل شوید و اگر کار نکرد سراغ بعدی بروید. آدرس‌های IPv6 فقط وقتی کار می‌کنند که اینترنت شما IPv6 داشته باشد.

نام پارامتر باید با حرف بزرگ (I1) باشد. فیلد خالی در کانفیگ نمی‌آید. مقدار پیش‌فرض فقط یک نمونه است؛ اگر کار نکرد مقدار دیگری بدهید.

اگر مرورگر درخواست مستقیم به Cloudflare را بلاک کرد (خطای CORS)، یک Worker بسازید. کدش پایین صفحه است.


  

    
    
  

  
در AmneziaVPN دکمه + را بزنید، «Insert» یا «File with connection settings» را انتخاب کنید.






  کد Cloudflare Worker برای پروکسی

export default {
  async fetch(req) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Headers': '*',
      'Access-Control-Allow-Methods': 'POST, OPTIONS'
    };
    if (req.method === 'OPTIONS') return new Response(null, { headers: cors });
    const r = await fetch('https://api.cloudflareclient.com/v0a2158/reg', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'User-Agent': 'okhttp/3.12.1',
        'CF-Client-Version': 'a-6.10-2158'
      },
      body: await req.text()
    });
    return new Response(r.body, {
      status: r.status,
      headers: { ...cors, 'Content-Type': 'application/json' }
    });
  }
}
